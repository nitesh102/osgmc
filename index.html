01 · Introduction

What is Free Space
Management?

Every time a file is created, resized, or deleted, the disk's free space changes. The OS must know exactly which blocks are free — otherwise it cannot safely store new data.

Definition

Free space management is the technique of tracking unused disk blocks so they can be allocated to new files and released back when a file is deleted.

A block's lifecycle

  1. Create

    A new file requests disk blocks to store its data.

  2. Allocate

    The OS assigns the first available free blocks.

  3. Record

    The free-space structure is updated instantly.

02 · Why It Matters

Why Free Space
Management Matters

  • Efficiency

    Every block is used wisely — little to no wasted storage.

  • Speed

    New files get space immediately by checking the free list.

  • Reuse

    Blocks from deleted files are reclaimed automatically.

  • Reliability

    The OS never overwrites data that is still in use.

03 · The Methods

Four Classic Techniques

Each method keeps a free-space list — the way they store it differs in memory cost and speed.

01

Bitmap

Bit vector

One bit per block — 1 = free, 0 = used.

Fast search · Simple
02

Linked List

Free list

Free blocks are chained together with pointers.

Compact · Easy update
03

Grouping

Batched addresses

One free block stores the addresses of many others.

Quick allocation · Large disks
04

Counting

First + count

Stores the first free block and how many follow.

Contiguous runs · Low overhead

The right choice depends on the allocation scheme and the size of the disk.

05 · Real-life Analogy

The Parking Lot Analogy

  • Parked cars = stored files
  • Parking manager = operating system

06 · Conclusion

Key Takeaways

  • Free space management tracks free blocks so storage is used efficiently.

  • Four methods — bitmap, linked list, grouping, counting — trade speed against memory.

  • The best choice depends on the allocation scheme and the disk size.

  • Reclaimed space is reused instantly, keeping performance high.
